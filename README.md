**Задание**

- Понять, что происходит в программе сейчас
- Добавить генератор яблок (создание в ячейке с координатами, кратными 10), отрисовывать яблоко красным цветом
- Добавить проверку на пересечение с яблоком - после метода Snake.Move добавить вызов метода CheckIntersect - в котором проверить, совпадают ли координаты головы змейки с яблоком. Если совпадают - надо создать новое яблоко
- Добавить змейке метод на увеличение длины. Вызвать увеличение при пересечении головы змейки с яблоком
- Добавить проверку на пересечение головы змейки с координатами одной из ее ячеек (если ячеек больше одной). Вызвать завершение игры при таком пересечении (snakeIsAlive = false).

- Добавить подсчет очков (+5 за хорошее яблоко, -3 за плохое). Очки можно выводить с помощью метода DrawText
- При поедании яблока ускорять игру. За скорость отвечает число в методе Thread.Sleep(X). X это миллисекунды ожидания, чем меньше число, тем быстрее змейка движется.
- Добавить вторую змейку, настроить кнопки для управления ей. Получится игра вдвоем
